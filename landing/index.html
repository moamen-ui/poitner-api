How it works

💬

Click & comment

Anyone signed in clicks any element on the running app and leaves a short comment.

Triage in the dashboard

Comments land in the dashboard tagged by project, environment, stakeholder, and status — triaged like real work, not buried in a doc.

>

Applied by AI

A developer hands the queue to any AI tool — Claude Code, Cursor, and more — which edits the real source files over plain HTTP.

Save time, cut costs, spend fewer AI tokens

Save time

Every comment already carries the exact element, page, and CSS that wins — no back-and-forth figuring out what someone meant.

Cut costs

Fewer status meetings and clarification threads — the context a call would've needed is already attached to the comment.

Spend fewer AI tokens

Captured selectors, routes, and source paths mean your AI tool starts at the right file instead of exploring the whole codebase to find it.

One organized queue

Install in Chrome

1 / 6
1

Download the extension

Grab the extension package (a .zip file).

Download .zip
2

Unzip it

Unzip the downloaded file — you'll get a folder with the extension inside.

3

Open Chrome extensions

In Chrome, go to chrome://extensions

4

Enable Developer mode

Turn on the “Developer mode” toggle in the top-right corner.

5

Load unpacked

Click “Load unpacked” and select the folder you unzipped.

6

Sign in & use it

Pin Pointer, click it, sign in with your account, then “Activate on this tab” on any site.
