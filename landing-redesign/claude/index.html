A comment is a structured brief, not a screenshot

Every click captures what your AI coding tool actually needs — no back-and-forth to ask what page, what element, or what rule is winning.

Field Why an AI tool cares
selector Identifies the exact DOM element without a screenshot or a description.
snapshot The element's own opening tag, attributes, and text — deliberately shallow so it doesn't drown the model in child markup.
appliedCssRules The rules that actually win, not the full computed dump — answers "why is it blue?" before the agent asks.
computedStyles, classes, parentInfo Disambiguates structure when the selector is generic.
route, pageUrl, pageTitle Identifies which screen or view to open.
viewport, deviceType, devicePixelRatio Turns "broken on mobile" into a reproducible condition.
PageContextSnapshot Opt-in for bug reports: console errors and failed or slow network requests at the moment of the issue.
sourcePath The source file path, when source mapping is enabled for the project.
language The language tag the comment was detected in.

How it works

One loop, four steps, always ending back with the person who asked.

1

Point & comment

Anyone signed in clicks an element on the running app and leaves a short comment, in whatever language they think in.

2

Triage in the dashboard

Comments land tagged by project, environment, and stakeholder, so nothing gets lost in a chat thread.

3

Applied by AI

A developer hands the queue to any AI coding tool over plain HTTP — Claude Code, Cursor, Windsurf, or whatever they already use.

4

Committed, never pushed

The AI commits the fix in the project's own style and links it back to the comment. It never pushes — a human reviews the diff before anything ships.

Wrote the comment in Arabic, Spanish, or anything else? The reply comes back in the same language you used.

Feedback on sites you don't host

The browser extension gives you the same click-to-comment flow on any site — no code to install there.

Download the extension package to your computer.

Download extension (.zip) Install from the Chrome Web Store

Unzip the downloaded file into a folder you'll keep around — Chrome loads the extension from that folder directly.

Open a new tab and go to:

chrome://extensions

Turn on "Developer mode" using the toggle in the top-right corner of that page.

Click "Load unpacked" and select the unzipped folder from step 2.

Click the Pointer icon in your toolbar and sign in. You're ready to comment on any site.
