The Living Spec

The Structured Brief

Every comment carries the exact DOM, style, and runtime state an AI tool needs to touch the right file on the first turn.

Field Why an AI tool cares
selector Identifies the exact DOM element without a screenshot or a description
snapshot The element's own opening tag, attributes (≤120 chars), text (≤160 chars) — deliberately shallow so it doesn't drown the model in child markup
appliedCssRules The rules that win, not the full computed dump — answers "why is it blue?" before the agent asks
computedStyles, classes, parentInfo Disambiguates structure when the selector is generic
route, pageUrl, pageTitle Identifies which screen/view to open
viewport, deviceType, devicePixelRatio Turns "broken on mobile" into a reproducible condition
PageContextSnapshot Console errors and failed/slow network requests at the moment of the issue (opt-in for bug reports)
sourcePath Configured attribute or framework dev-mode path when present (when source mapping is enabled)
language The BCP-47 tag the comment was detected in

Feedback Loop

How it works

Four steps from raw feedback to a verified local commit.

01

1. Point & comment

Anyone signed in clicks an element on the running app and leaves a short comment in whatever language they think in.

02

2. Triage in dashboard

Tagged by project, environment (Local, Staging, Production), stakeholder, and status in one unified queue.

03

3. Applied by AI

A developer hands the queue to any AI coding tool over plain HTTP. Non-English comments are translated automatically.

04

4. Committed, never pushed

The AI commits per project style and links each applied comment back to author. It never pushes — human reviews the diff.

Worker Model Translation

Non-English comments are translated in, and replies translated back out, by a lightweight model — never the expensive orchestrator.

Security & Ethics

Trust & privacy

Strict boundaries around your code, your data, and your user privacy.

An AI edits my code?

The AI commits locally; it never pushes. Every applied comment carries its git commit URL so you can inspect the diff before anything touches your repository.

What do you capture?

Element-level DOM metadata only: selector, shallow HTML snippet, winning CSS rules, and route. Never passwords, form inputs, session cookies, localStorage, or API request bodies. See our Data & Self-Hosting and Privacy Policy pages.

Data & Self-Hosting Guide · Privacy Policy

Which AI tool do I use?

Any AI coding tool you already use (Claude Code, Cursor, Windsurf, OpenCode, Antigravity). Plain HTTP integration with zero vendor lock-in.

Is my data stuck with you?

Fully self-hostable. Run the open API and Postgres database on your own infrastructure so data never leaves your network.

Step 1: Download Extension

Download the extension package or install directly from the Chrome Web Store.

Install Extension

Step 2: Extract Archive

Unzip the downloaded archive into a permanent folder on your local machine.

Step 3: Open Chrome Extensions

In Chrome, Brave, or Edge, navigate to chrome://extensions in the address bar.

Step 4: Enable Developer Mode & Load

Toggle Developer mode in the top-right corner, click "Load unpacked", and choose the extracted folder.

Step 5: Sign in & Point

Click the Pointer icon in your browser toolbar, sign in, and click any element on the running web app.
