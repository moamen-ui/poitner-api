## Preconditions

- Seed complete (`state/credentials.json`, `state/keys.json`); personas used: DEV (`USERS.developer`), SA (`SUPER_ADMIN`). Role shorthand per testing-review §3.
- Prerequisite docs merged: R1-02 (`init`), R1-04 (`doctor`), R1-07 (workflow). CLI built: `cd cli && npm run build`; `CLI_ENTRY=node <repo>/cli/dist/cli.js`.
- `e2e/scripts/serve-dir.mjs` exists (R2-00 task 3b) and serves any dir on a port. **Decision:** the branding helpers live at `e2e/scripts/set-branding.mjs` + `e2e/scripts/reset-branding.mjs` (harness §4 layout is binding, superseding the execution doc's `e2e/whitelabel/` paths); both log in as `SUPER_ADMIN` and `PUT /api/admin/branding` (super-admin-gated, `Admin/BrandingController.cs:19`) using `BrandingWriteDto` field names `productName`, `tagline`, `urls.app`.
- Branding defaults for restore (`BrandingService.cs:10-16`): `productName "Pointer"`, `tagline "Point at the UI. Ship it with AI."`, `urls.app https://app.pointer.moamen.work`.
- Fresh projects are created with `enforceAllowedOrigins` default **false**, so the widget renders on any origin; each spec still asserts the gate: `GET /api/public/projects/{key}/widget-status?origin=http%3A%2F%2Flocalhost%3A4174` → `data.active === true`.
- Generators pinned to a minor and run with npm cache present: `npm create vite@6.0 -- --template vanilla-ts`, `npx @angular/cli@20.0 new fresh-ng --defaults --skip-git --skip-install`, `npx create-next-app@15.0 --ts --app --no-eslint --use-npm --yes`.
- Ports: fresh preview **4174** (`--strictPort`); registry in `lib/constants.mjs`. Generated apps live under `e2e/state/fresh/<stack>/` (gitignored).
- `run-e2e.sh --fresh` / `--whitelabel` flags wrap the phases; **the whitelabel phase always runs `node e2e/scripts/reset-branding.mjs` in a `finally`** (harness §8).

## Flake notes

- npm scaffolding nondeterminism → pinned **minor** generator versions + npm cache; exactly one whole-stack retry on the 300 s budget (harness §9).
- `vite preview` and `serve-dir.mjs` both use `--strictPort` 4174; started/killed by `run.mjs` `finally` so a failed stack never leaks the port into the whitelabel phase.
- Widget boot race: always `waitForResponse('**/capture-config')` before interacting (harness §9); the fresh apps inject the widget with `environment=local`, so comments land in env 1 — assert with the unfiltered list or `environment=1`.
- R2-00-06/08 must run **inside** the R2-00-05 brand window and before `reset-branding.mjs`; ordering is `run.mjs --brand-check` (CLI) → widget specs → `finally` reset → R2-00-07 assert.
- `next`/`angular` scaffolds are nightly-only (runtime + npm variability); PR runs only execute them when `cli/**` changed.
