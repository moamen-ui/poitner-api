## Flake notes

- `doctor --refresh-stack` in R3-02-02 step 4 runs against a dead server URL — keep the env rewrite + restore inside one test so a failure cannot leak `http://localhost:9` into later scenarios.
- The recording proxy must die in `finally` (`--strictPort`); it is the only listener allowed on 4179.
- `apply --plan` depends on seeded ReadyToApply comments — this spec runs in the cli phase (after seed, per §8 phase order); never create the temp repos under `e2e/state/fresh/` (fresh-app owns that tree).
- Repeat `POST /stack` calls are append-if-new (`ProjectStackController.cs:9-14`) — do not "clean up" the stack between runs; asserting the same `frontend` list twice is the intended behaviour, not drift.
