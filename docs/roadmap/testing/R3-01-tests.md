Harness: [`00-HARNESS.md`](00-HARNESS.md). Execution doc: [`../execution/R3-01-vite-plugin-manifest.md`](../execution/R3-01-vite-plugin-manifest.md).

## Covers

Acceptance criteria of R3-01: AC-1 (two clean clones → identical `entries`) → R3-01-05 · AC-2 (`POST /builds` 400/403/404/repeat) → R3-01-06 · AC-3 (prod build stamps every root, Fragment all roots, component-only root none) → R3-01-01 · AC-4 (`manifest.json` gitignored) → R3-01-01 step 6 · AC-5 (widget comment carries the hash; `pointer get --json` → `resolvedSource`) → R3-01-01 · AC-6 (rename → stale warning + prev hint) → R3-01-02 · AC-7 (`apply` stores `commitSha`; `status --deployed` marks ancestors only) → R3-01-04 · AC-8 (widget beacon once, `✓ live`) → R3-01-03 · AC-9 (old comments never deployed) → R3-01-03 step 9 / R3-01-06. AC-10 (unit + dashboard) is unit-level, not covered here.

## Preconditions

- Seed complete (`credentials.json`, `keys.json`); personas: `USERS.developer` (DEV — CLI/plugin), `USERS.tester` (QA — widget), `TENANT_OWNER` (WA — apply/`status --deployed`), `CLIENT` (CL — quick-access negative), `TENANT_B_OWNER` (TB — cross-tenant negative).
- Prerequisite docs merged: R2-01 (`apply`, `get --json`, `status`), R1-01 (gitignore), R3-01 itself.
- Fixture `e2e/fixture-app/vite-react/` (R3-01 task 13b): React + Vite + Tailwind; components `Card` (single root `<div class="card">`), `PlanList` (Fragment → `<h2>` + `<ul>`), `TrackedCard = memo(Card)` (HOC), `Shell` (returns only `<Card/>`, no host root), plus a `<form>` with `<input id="email" type="email">` and a `<button id="cta">`. `vite.config.ts` uses `pointerSource({ enabled: process.env.VITE_POINTER_SOURCE === 'true' })` from `pointer-feedback/vite` via a `file:../../../cli` dependency. `index.html` embeds the widget via `/embed.js?project=e2e-alpha&environment=staging` from `http://localhost:8090`.
- Build helper `e2e/scripts/lib/vite-fixture.mjs`: `buildFixture({ dir, buildSha, enabled = true })` runs `npm ci` (once, cached in `state/`), then `VITE_POINTER_SOURCE=<enabled> npm run build` inside a **temp git repo** (`lib/git.mjs tempRepo()` — the plugin reads `git rev-parse --show-toplevel` and `HEAD`; the fixture is copied there so the hash's `repoRelativePath` is `src/components/…`), returns `{ distDir, manifest, repo }`. Serves `dist/` with `serve-dir.mjs <dist> 4175`.
- Env: `CLI_ENTRY` set (§6 of the harness). Project `e2e-alpha` active for Staging.

## Flake notes

- `buildFixture` runs `npm ci` once per suite (cached under `state/vite-react/node_modules`); the build itself ~10–20 s — nightly tier only.
- R3-01-03 counts `/builds` calls with `page.route` **before** `goto`; the widget posts fire-and-forget, so wait for the response, then `expect.poll` for 3 s to prove no second call.
- Serve the fixture on **4175** only; kill via the `run-e2e.sh` trap.
- `builds` policy is 30/min per user: R3-01-06 issues ≤ 12 requests per user — safe; never loop it.
- R3-01-04 needs `git config user.email` in the temp repo (feeds `appliedByLabel`).
