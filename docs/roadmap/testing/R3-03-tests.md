Restore from the backup + assert `git status --porcelain -- API/wwwroot/pointer.version.json API/wwwroot/widget` is empty in the phase `finally`.
- Caddy (nightly only): `docker compose -f docker-compose.yaml -f e2e/compose.caddy.yaml up -d caddy` — `caddy:2-alpine`, ports `8443:8080`, command `caddy run --config /etc/caddy/Caddyfile.e2e --adapter caddyfile`; **new** `e2e/Caddyfile.e2e` = a `:8080` site whose `@widget` matcher + `header` lines are copied **verbatim** from the repo `Caddyfile` (post task 7, i.e. including `not query v=*`), upstream `reverse_proxy api:8080`. - Project `e2e-widget-smoke` ensured by shared helper `e2e/widget/lib/ensure-smoke-project.ts` (extracted from `widget.spec.ts:22-36` — idempotent 409-tolerant create via wsAdmin).
- Pinned pages are **route-fulfilled, not served**: **new** `e2e/widget/lib/pinned-page.mjs` `pinnedPage({ v, integrity, project })` returns the §C HTML (script `http://localhost:8090/pointer.js?v=<v>` + `integrity` + `crossorigin="anonymous"` + `defer`, then `<pointer-feedback project="e2e-widget-smoke" server="http://localhost:8090">`); specs `page.route('**/pinned.html', r => r.fulfill({ contentType: 'text/html', body }))` **before** `goto('http://localhost:<PORTS.pinned>/pinned.html')` (Decision: `PORTS.pinned = 4180` registered in `constants.mjs`; interception fires before the network so nothing listens there).
- `pinned-tamper` fixture (Decision): **new** `e2e/fixture-app/pinned-tamper/proxy.mjs` on `PORTS.pinnedTamper = 4177` — node http proxy: `GET /pointer.js*` → fetch the same path+query from `http://localhost:8090`, XOR byte at index 200 with `0x20` (one byte changed, Content-Length identical, guaranteed hash mismatch, framing untouched), respond with the same content-type **and** `Access-Control-Allow-Origin: *` so the *only* failure is SRI; serves `/` = `pinnedPage({ v: <current H>, integrity: <real> })`; every other path proxied verbatim. Started/killed by the spec (`--strictPort`, `finally`).
- `csp-nonce` fixture (Decision): **new** `e2e/fixture-app/csp-nonce/serve.mjs` on `PORTS.cspNonce = 4176` — serves `index.html` (smoke-style bootstrap, project `e2e-widget-smoke`, latest `/pointer.js`) and `/pinned.html` (`pinnedPage` with `v = H`), every response carrying the header `Content-Security-Policy: default-src 'self'; script-src 'self' http://localhost:8090; style-src 'nonce-pfe2e'; connect-src http://localhost:8090; img-src http://localhost:8090 data:` (Decision: CSP as a response header, not `<meta http-equiv>` — Chromium ignores nonces delivered via meta).
- CORS decision: §C uses `crossorigin="anonymous"`, so pinned JS/CSS responses must carry `Access-Control-Allow-Origin: *` (asserted in R3-03-06 row 4; implementation note for task 5).
- Smoke fixture on 4173 as today (`run-e2e.sh` phase 4 pattern).

## Flake notes

- The fabrication + `restart-api.mjs` runs **once**, before the widget phase; both R3-03-02 and R3-03-06 consume it — do not restart per spec. Restore + `git status` cleanliness assert lives in the phase `finally`, before any later phase reads `API/wwwroot/`.
- `page.route` must be registered **before** `goto`; route-fulfilled pages have no listener on 4180 — never add a server there.
- The tamper proxy flips exactly one byte (index 200, XOR `0x20`) and re-echoes `content-length`/`access-control-allow-origin` — anything else turns an SRI failure into a CORS/framing failure and invalidates step 7.
- Caddy must start only after `/api/branding` answers on 8090 (run-e2e.sh ordering); `--strictPort` and trap kills for 4176/4177 per §9.
- `R3-03-04` step 3 reads `adoptedStyleSheets` — the fallback fires on the link's `error` event only; if the assertion races, wait for the `/pointer.css` fetch response first (the fallback's own fetch), never a fixed sleep.
- `#pf-add` visibility timeout 10 s matches `widget.spec.ts:65`; the pinned pages gate on `/widget-status` for `e2e-widget-smoke` — run `ensure-smoke-project` in `beforeAll`.
