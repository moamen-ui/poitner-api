## Gemini 3.1 Pro (agy)

| severity | finding | evidence | suggested fix |
|---|---|---|---|
| LOW | Unhandled `DbUpdateConcurrencyException` in `CancelDeletionAsync` race | §3.4 `CancelDeletionAsync`, §3.9 `ExecuteDueDeletionAsync` | If an admin cancels at the exact millisecond the deletion job runs, EF Core will block the `UPDATE` until the job's `FOR UPDATE` transaction commits, then throw `DbUpdateConcurrencyException`. Wrap the cancel `SaveChangesAsync` in a `try/catch` and return `Conflict` or `NotFound` rather than a 500 error. |
| LOW | `WorkspaceStateService.GetAsync` evaluates soft-deleted rows | §3.3 `IWorkspaceStateService` | `Workspaces.IgnoreQueryFilters().AsNoTracking()` will return soft-deleted workspaces. Add `&& w.DeletedAt == null` to the lookup to ensure they reliably return missing (not-frozen), matching the tracked load in §3.4. |
| NIT | 429 Too Many Requests handling in Dashboard | §3.7 `danger` policy, §11 Task 2 | The `POST deletion/request` is rate-limited to 10/10m. Ensure the frontend explicitly catches 429 responses and displays the `envelope.message` gracefully if the global interceptor doesn't already handle it. |
| NIT | CLI reads are successfully blocked while Dashboard reads pass | §3.5 `WorkspaceFrozenFilter`, D18.4 | Working exactly as designed. The filter deliberately blocks `GET /api/export` for API-key sessions (stopping CLI scraping), while letting JWT `GET` sessions (Dashboard) export successfully. |
| NIT | `ConfirmDeletionAsync` handles operator pause race correctly | §3.4 `ConfirmDeletionAsync` | Working as designed. The `SELECT ... FOR UPDATE` lock combined with the `!PausedByOperator` re-check safely aborts the confirmation if an operator pauses it concurrently. |
| NIT | Anonymous `UploadsController.GetFile` bypasses the filter | §3.5 filter rules | Working as designed. Since it is a `GET` request (required for `<img src>` tags in emails/exports) and doesn't write data, no state mutation can slip through this `AllowAnonymous` path. |
| NIT | Erase tokens cannot be used to delete workspaces | §6 Test 4, R16 | Working as designed. The explicit `TokenPurposes.DeleteWorkspace` prevents a cross-use of an `erase` token, adhering to R16 token purpose segregation. |
