# Schema map (as of 2026-09-22, `main` @ `03093ad`; amended after DB-04 shipped at 7a015cb)

Plain-language map of the 25 tables, who owns each row, which query filter applies, and the
invariants that hold. Regenerated by the db-architect on each review rather than patched. Source of
truth is `Infrastructure/Migrations/AppDbContextModelSnapshot.cs` + `Infrastructure/Mappings/*.cs`.

**Conventions that hold everywhere:** `snake_case` physical names; `int identity` PK `id` (except
`usage_events`, still int but not a `BaseEntity`); audit columns `created_at/created_by/updated_at/
updated_by/deleted_at/deleted_by` stamped in `AppDbContext.SaveChangesAsync`
(`Infrastructure/AppDbContext.cs:168-194`); soft delete = `deleted_at IS NOT NULL`, enforced by
explicit predicates, not a global filter; all timestamps `timestamptz`; enums stored as `int`.

**Tenancy today:** a workspace is the uuid in `owner_id`; it equals the founding Workspace Admin's
`users.public_id`; it is the JWT `tenant` claim (`Infrastructure/Auth/JwtTokenService.cs:33-34` →
`HttpCurrentUser.TenantId`, `Infrastructure/CurrentUser/HttpCurrentUser.cs:24-27`). Super admins
have `owner_id = NULL` and bypass every filter. No table has an FK on `owner_id` (fixed by DB-03).

Filter shapes (`AppDbContext.cs:76-147`):
- **strict-own** — `IsSuperAdmin || OwnerId == TenantId` (+ legacy null-bucket branch, disabled in prod by `Tenancy:StrictNullTenantIsolation=true`, `docker-compose.prod.yml:30`)
- **own+global** — strict-own **or** `OwnerId IS NULL` (seeded catalog rows every tenant sees)
- **none** — global catalog / exempt

**Cross-table facts worth remembering**

- Deleting a **project** hard: cascades `project_app_urls`, `project_builds`, `page_context_snapshots`; **blocked** by any `comments` or `notifications` (Restrict). Orphans (no FK): `predefined_actions`, `predefined_action_suggestions`, `ai_rules`, `quick_access_links`, `invites.project_id`, `usage_events.project_id`.
- Deleting a **user** hard: cascades `api_keys`; every uuid reference (`author_id`, `created_by`, …) dangles by design.
- Deleting a **workspace**: `TenantService.HardDeleteAsync` (`TenantService.cs:356-441`) handles 6 of 23 owner-carrying tables; see DB-03.
- Filtered indexes and value converters are **not** exercised by the InMemory test provider; Sqlite honours the partial index filter strings (column names are snake_case in both) but cannot run the Npgsql migrations (`EnsureCreated` only). Postgres behaviour is proven only by the R11 rehearsal.
